# Stopped session recovery

A supervisor stop can leave an unconfirmed logout while its saved end is `stopped after 1 runs`. Authenticated recovery must accept that end only with the existing exact task authorization, held producer attempt, current native qualification and disabled assignment. Owner stop files remain authoritative. Consumer: Swordswallow and Unsheathed cloud migration cleanup. Evidence: `.practice/cloud-coordinator/handoff.json` in the cloud runtime. Gap: native qualification of the changed runtime and controlled rollout are required before live recovery.

Source -> local consumer -> reuse -> check: `packages/core/src/session-recovery-permit.ts` -> authenticated cloud cleanup -> extend existing permit admission -> stopped-end regression and native recovery delivery.
