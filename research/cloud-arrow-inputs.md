# Cloud arrow inputs

Cloud feathers need an owned knife and normal logs before headless-arrow processing. Source -> consumer -> adapt -> check: `scripts/generated/woodcutting.ts` -> a feather holder with bronze axe and no cash -> bounded normal-log supply mode with knife pickup, observed bank storage and the existing shaft/headless helpers -> actual worker CLI native save and asset reconciliation. `scripts/fletch-shafts.ts` owns log accounting; `scripts/fletch-arrows.ts` owns headless accounting. Existing levelling woodcutting drops logs and consumes normal logs for its tick trick, so it does not qualify as retained supply.

Finite live consumer: Swordswallow after Cook’s Assistant, at Draynor with starter kit and 2,040 feathers banked, supplies 25 logs, processes 375 shafts and 165 headless arrows, preserving the remaining feathers and kit. Native actual-CLI proof: `.practice/arrow-inputs/verified-proof.json` verifies 165 banked headless arrows, 210 shafts, 1,875 feathers, an owned knife, unchanged HP and confirmed logout. Gap: one matched live pilot; this mode is not batch-ready.
